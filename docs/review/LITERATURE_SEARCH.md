# Literature search and novelty status

This document records the literature search conducted on `2026-07-14 JST
(UTC+09:00)`.

## Result

No published or publicly posted source located in the search explicitly states

\[
H(N)\le N^{1/3+o(1)}
\]

for Erdős Problem 160.

No direct precedent was found for the \(O(p)\)-colour proper-ABBA construction
using the norm \(\mathbf F_{p^3}\to\mathbf F_p\), its nine-state carry label,
and its composition with the other filters. The construction may nevertheless
be known under different terminology or as folklore.

## Closest located material

- [Erdős Problems 160](https://www.erdosproblems.com/160) remains open and
  records the exponent \(\log 3/\log 22\).
- [Zach Hunter's E160 comment](https://www.erdosproblems.com/forum/thread/160)
  combines a Behrend-style subpower filter with the 22-to-3 seed. It does not
  state a one-third bound or the cubic norm mechanism.
- [Deng–Tidor–Zhao](https://arxiv.org/abs/2307.06914) supplies the closest
  digit/sphere and symmetric-colouring framework. It does not state the
  candidate E160 bound.
- [Cameron–Heath](https://arxiv.org/abs/1702.06227) obtains a one-third-scale
  colour count in a different edge-colouring problem. It is conceptually
  adjacent, not the same theorem or norm construction.
- A [MathOverflow discussion](https://mathoverflow.net/questions/410808/)
  uses finite-field three-dimensional structure for a weaker E160 upper, but
  not the norm-ABBA factor.
